# Dedicación CC0 del dataset procedimental AvatarFace

**Fecha de confirmación:** 2026-08-13
**Declarante:** David Arturo Silva, titular del proyecto AvatarFace.

El declarante dedica a **CC0 1.0 Universal** las imágenes PNG, captions,
atributos y manifiestos producidos por `avatarface-procedural-v2`, incluidos los
datasets generados con los parámetros congelados en
`configs/regression-fixtures.json`.

La dedicación se aplica solamente a esos activos procedimentales propios. No
cubre el código, la documentación general, dependencias, modelos, pesos ni
cualquier activo de terceros. El código y la documentación propios se publican
bajo Apache-2.0; cada tercero conserva sus términos aplicables.

Texto legal canónico: <https://creativecommons.org/publicdomain/zero/1.0/>.
CC0 no elimina derechos de privacidad, imagen, marcas u otros derechos de
terceros. El dataset indicado no representa personas reales ni utiliza activos
externos.
